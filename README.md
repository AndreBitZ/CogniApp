🧠 Treino Cognitivo Web App

Bem-vindo ao repositório do Treino Cognitivo, uma aplicação web desenvolvida para ajudar no treino percetivo-cognitivo e na melhoria dos tempos de reação de atletas. Inspirada em sistemas profissionais de treino, esta app utiliza estímulos visuais e auditivos aleatórios para desafiar a velocidade de processamento e a agilidade mental.

🎯 Objetivo

O foco principal desta ferramenta é fornecer um ambiente de treino simples, mas eficaz, ideal para guarda-redes de andebol, futebol e outros desportistas que dependem de reações rápidas a estímulos imprevisíveis.

✨ Funcionalidades
 
Estímulos Visuais Aleatórios: A app apresenta uma combinação imprevisível de cores vibrantes e setas direcionais.
 
Intervalos Imprevisíveis: O utilizador pode definir o intervalo de tempo mínimo e máximo. A app irá gerar os estímulos num momento aleatório dentro dessa janela de tempo, garantindo que o atleta nunca consegue antecipar o próximo sinal.

Feedback Auditivo: Cada estímulo visual é acompanhado por um sinal sonoro (beep) sintetizado diretamente pelo browser, reforçando o tempo de reação multissensorial.
 
Interface Simples e Responsiva: Desenvolvida em HTML puro, utilizando Tailwind CSS para garantir que a interface é limpa, sem distrações e funciona perfeitamente em computadores (macOS, Windows) e dispositivos móveis (iOS, Android).
